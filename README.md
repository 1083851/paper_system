迷宮學園：運算思維學習平台 - 系統安裝與使用說明書
一、 系統環境需求與安裝步驟
本系統採用 Node.js 執行環境與 MongoDB 資料庫架構，請依照以下步驟在伺服器或本機端完成部署與啟動：
1. 環境需求
- Node.js (建議版本 v18.x 或以上)
- MongoDB (本地端服務或 MongoDB Atlas 雲端資料庫)
2. 安裝與設定步驟
(1) 下載與解壓縮專案：將專案檔案放置於工作目錄中。
(2) 安裝相依套件：開啟終端機（Terminal），於專案根目錄執行以下指令：npm install
(3) 建立環境變數檔 (.env)：在專案根目錄建立 .env 檔案，填入以下設定：
PORT=3000
MONGO_URI=您的MongoDB連線字串
JWT_SECRET=您的JWT密鑰字串
GEMINI_API_KEY=您的GoogleGeminiAPI金鑰
(4) 啟動伺服器：執行 node server.js。當終端機顯示 MongoDB 成功連線與伺服器啟動完成即代表系統啟動成功。
二、 系統操作說明
1. 受試者端操作 (login.html & game.html)
- 註冊與登入：開啟瀏覽器進入首頁，輸入自訂帳號與密碼進行註冊或登入。系統將自動賦予 AI 伴學權限。
- 視覺化程式闖關：進入遊戲後，透過拖曳 Blockly 視覺化積木來控制小貓咪移動、轉彎與執行，點擊紅色回家按鈕執行程式。
- AI 貓導師互動：若在解題過程中遇到困難，可隨時點擊介面中的求助按鈕或使用語音輸入，與生成式AI動態鷹架進行對話，獲得對應的動態鷹架提示。
2. 管理者後台操作 (admin.html)
- 後台登入：使用具備管理員權限的帳號登入後，系統將自動導向管理介面。
- 實驗監控與資料管理：研究者可即時檢索全體學生的上線狀態、目前解鎖關卡、分數與歷史對話，並可進行帳號密碼維護與行為日誌匯出。
